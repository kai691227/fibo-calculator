費波導航系統 PWA V1.2

檔案：
- index.html
- style.css
- app.js
- manifest.json
- service-worker.js
- icon-192.png
- icon-512.png

功能：
- 點位模式：輸入最高最低，直接顯示上下四層與多空中心
- 完整模式：顯示區間、中心、比例、距離、最近位置
- 設定可新增、刪除、停用或修改層數
- 多空中心 =（高點 + 低點）÷ 2
- 多方點位 = 多空中心 +（區間 × 比例）
- 空方點位 = 多空中心 -（區間 × 比例）
- 已驗證的中心費波參數：0.336、0.544、0.6916、0.880
- 高點、低點、目前價格輸入
- 標準費波與延伸位置
- 自訂比例、名稱、啟用狀態
- 保存上次輸入與設定
- 顯示距離目前價格最近的費波位置
- 一鍵複製結果
- 支援安裝到手機主畫面
- 支援離線使用

重要：
PWA 必須透過 HTTPS 網址或 localhost 執行，不能只用檔案總管直接點開 index.html。
最簡單方式是把整個資料夾上傳到 GitHub Pages、Netlify、Cloudflare Pages 或任何 HTTPS 主機。

iPhone 安裝：
1. 用 Safari 開啟網址
2. 點「分享」
3. 點「加入主畫面」
4. 從桌面圖示啟動
